# Last Text at One Percent

A phone's last text as its battery hits 1 percent, written by a small
Node program that writes one line to `/output/entry.txt`.

> Before I go: I sent your boss the 'I quit' draft you never sent. You're free now. Tell my charger I loved her. — your phone, 1%

Run with `node main.ts` (Node 22). The line is 127 characters, inside the
1–200 character gate, in the phone's own voice: one concrete detail (the
unsent "I quit" draft) and a final twist — the phone already sent it.
